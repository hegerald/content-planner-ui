# Issue-Format

Entspricht dem Issue-Template `.github/ISSUE_TEMPLATE/feature.yml` – gleiche Abschnitte,
damit Issues von Menschen und von Agents gleich aussehen.

```markdown
## Ziel
<Warum wird das gebraucht? 1–2 Sätze>

## User Story
Als <Rolle> möchte ich <Funktion>, damit <Nutzen>.

## Akzeptanzkriterien
- [ ] Given <Ausgangslage>, when <Aktion>, then <Ergebnis>
- [ ] … (mindestens ein Fehlerfall mit erwarteter Meldung)

## Betroffene Komponenten
- <Komponente>: <ja/nein – was>
- API-Contract: <neue/geänderte Felder oder Endpunkte, rückwärtskompatibel?>

## Annahmen
- …

## Nicht Teil dieses Issues
- …
```
